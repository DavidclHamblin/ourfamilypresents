# Our Family Presents

Website for www.ourfamilypresents.com, the umbrella site for the Family Presents group: Family Board Books, Family Storybooks, Family Learn to Read, Family Photo Calendars and Family Jigsaw Puzzles. Built on the same design system as Family Board Books.

- `src/build.py`  builds the site into `dist/` (`python3 src/build.py`). The brand list and each brand's status (live, soon, planned) are at the top of this file.
- `assets/css/site.css`, `assets/js/site.js`  styles and the launch-news sign-up (FormSubmit, emails hello@familyboardbooks.com)
- `.github/workflows/pages.yml`  publishes `dist/` to GitHub Pages on every push to main

No customer photos are ever published here; all drawings are our own.
